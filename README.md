## 🚀 Getting Started

### Prerequisites

- **Node.js** (v16 or higher)
- **npm** (comes with Node.js)
- **Git** (for cloning the repository)

### Installation

1. **Clone the repository**
```bash
git clone https://github.com/andargbogalle-lab/andarg_portifolio.git
cd andarg_portifolio
```

2. **Install dependencies**
```bash
npm install
```

3. **Start the development server**
```bash
npm run dev
```

4. **Open your browser**
```
http://localhost:5173
```

### Building for Production

```bash
npm run build
```

The optimized production files will be generated in the `dist/` folder.

### Preview Production Build

```bash
npm run preview
```

## 🎨 Customization

### Theme Colors

Edit theme variables in `src/index.css`:

```css
[data-theme="light"] {
  --primary-color: #6366f1;
  --secondary-color: #8b5cf6;
  /* ... more variables */
}
```

### Personal Information

Update these components with your information:

- **Header** (`src/components/Header.jsx`) - Logo and navigation
- **Hero** (`src/components/Hero.jsx`) - Name, title, and introduction
- **About** (`src/components/About.jsx`) - Bio and services
- **Projects** (`src/components/Projects.jsx`) - Your projects
- **Skills** (`src/components/Skills.jsx`) - Your technical skills
- **CV** (`src/components/CV.jsx`) - Education and experience
- **Contact** (`src/components/Contact.jsx`) - Contact details

### Meta Tags

Update SEO and social media tags in `index.html`:

```html
<meta property="og:title" content="Your Name" />
<meta property="og:description" content="Your Title" />
```
